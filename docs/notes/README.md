# Notes

This directory contains temporary, non-normative investigation and discussion. Notes do not define
current behavior, approved design, or roadmap commitment.

Note files use `YYYY-MM-DD-slug.md`, for example `2026-08-04-source-coverage.md`. A note states its
question, relevant evidence, and status. It must not contain credentials, recipient identifiers,
live portfolio data, generated reports, or copied provider data.

When a decision is accepted, update the relevant formal design or roadmap in the implementing
change, then delete the note or retain only evidence that remains independently useful. Readers
must never need a note to understand the current system contract.
