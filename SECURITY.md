# Security Policy

## Supported versions

MarketSieve has no stable release yet. Security fixes apply to the latest commit on `main` until
the first supported version is published.

## Reporting a vulnerability

Do not open a public issue for credentials, personal recipient data, provider tokens, or a
vulnerability that could expose them. Use GitHub's private vulnerability reporting for this
repository. If that channel is unavailable, contact the maintainer through the GitHub profile and
request a private reporting channel without including sensitive details.

Reports should include affected versions or commits, reproduction conditions, impact, and any
suggested mitigation. No response-time guarantee is made before the first stable release.
