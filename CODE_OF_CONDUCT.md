# Code of Conduct

## Our standard

Contributors and maintainers must communicate respectfully, welcome constructive disagreement, and
focus feedback on the work. Harassment, discrimination, threats, publication of private
information, and sustained disruption are not acceptable.

## Scope

This standard applies to repository issues, pull requests, discussions, reviews, and other spaces
where a participant represents MarketSieve.

## Enforcement

Report conduct concerns privately to the maintainer through the GitHub profile. Do not include
sensitive details in a public issue. The maintainer may edit or remove contributions, restrict
participation, or ban participants when necessary to protect the project community.
